These apply straight away and are remembered in this browser.

Version …. The board checks for a new version about every 10 minutes and whenever you come back to the tab. This button forces a full refresh of the page, styles and scripts, skipping every cache.
Copies everything configured in this browser: repository, username, access token, theme, card style and view. Open the setup link, or paste the code below, on your other browser or phone. Treat both like a password.
Recorded as the author of your edits and comments, and used for unread markers and the default assignee.
Create a fine-grained token on GitHub → (the link pre-fills the name, expiry and Contents: Read and write plus Issues: Read and write, needed for the Create issue button). Choose Only select repositories and pick just the repo that holds your board file. If the repo belongs to an organisation, set Resource owner to that organisation. The token is kept only in this browser (localStorage) and is sent only to api.github.com.

Typing @claude in a comment can start your own Claude routine. Each person sets up their own; these values stay in this browser (like the GitHub token) and travel with "Copy settings code".

Paste it into a new chat with Claude (Claude Code, the desktop app or claude.ai). Claude reads the setup guide and offers to guide you or to do the clicking in your browser. It never handles your secrets: you paste those yourself.
Setup guide: board/ROUTINE-SETUP.md (or ask Claude Code in the repo to "set up my board routine"). From claude.ai/code/routines → your routine → Edit → add an API trigger → copy the URL and generate a token. The token can only start that one routine.
Browsers can't call a routine directly, so a one-off job on your free cron-job.org account makes the call (Settings → API → enable, create a key). What cron-job.org sees: your routine token and the task number (never the task's text); the job is deleted as soon as it has run. Starting takes about one to two minutes.
